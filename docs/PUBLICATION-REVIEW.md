# Pre-publication review

Reviewed on 2026-10-23 for the initial public release of this repository.

## Scope and findings

- Checked all reachable commit and annotated-tag metadata, historical file blobs, nested XPI/ZIP contents, and all 11 existing Release assets. Pattern scans and manual review found no remaining private author email, personal machine username/path, credential, personal-library report, or real-paper content in the material prepared for publication. The maintainer's public GitHub handle and GitHub noreply identity are intentionally retained.
- Rebuilt the Git object database using the maintainer's public GitHub identity. Version order and tag names are preserved; commit and tag object hashes changed. All historical file trees are identical to their corresponding reviewed snapshots.
- Verified all five XPI packages byte-for-byte against the runtime sources and license files in their corresponding version tags. The original installation packages remain unchanged.
- Reviewed the dependency declarations, runtime source, icon, synthetic PDF generator, and packaged files. No bundled third-party runtime source, embedded font program, Zotero logo, or third-party paper was found. The PDF fixtures are synthetic test documents generated by the included script; the icon is a small SVG path asset. Local Zotero implementation snapshots are excluded from Git and release packages.
- Version 0.4.1 uses AGPL-3.0-only, includes the complete LICENSE and project NOTICE, and has a corresponding-source archive. Versions 0.1.0 through 0.4.0 retain their MIT license. This change does not revoke earlier grants.
- The default README is English, with a linked Simplified Chinese guide. Both disclose heuristic-counting limits, incomplete interface localization, manual updates, and local-cache privacy considerations. This project is an independent third-party plugin without Zotero affiliation or endorsement.

## Limits

This is an engineering and publication review, not legal certification, an exhaustive security audit, a trademark clearance, or a guarantee of non-infringement in every jurisdiction. Pattern matching cannot prove the absence of every kind of secret or personal information. Future contributions and releases require their own review.

The repository does not include a user's Zotero database, PDFs, full-text cache, or plugin data. Users should redact local paths and identifiers before sharing logs or statistics caches in public issues.
